# Changelog

All notable changes to Open PDF Viewer. Versions follow SemVer; the Android versionCode goes up by one each release.

## 0.47.0 (2026-11-24)

- Recognize text (Tools…): offline OCR with Tesseract and the Portuguese and English models packaged with the app (nothing is downloaded). Each page is read word by word and an invisible text layer is added, so scanned PDFs can be searched and their text selected and copied; the page images do not change. Progress is shown per page; pages that already have text can be skipped.
- New dependency: Tesseract4Android (Apache-2.0, with Leptonica, libjpeg-turbo and libpng); models from tessdata_fast (Apache-2.0), fetched by tools/fetch-tessdata.sh. The universal APK grows from about 26 MB to 50 MB (see README › Size).

## 0.46.0 (2026-11-24)

- Scan to PDF (home screen › ⋮): take photos with the system camera app (the app asks for no camera permission) or pick them from the gallery. The page is found and straightened automatically, the corners can be adjusted, and a filter cleans it up (original, gray, or black-and-white document that ignores shadows). Several pages make one A4 PDF. No ML Kit and no network.

## 0.45.0 (2026-11-24)

- Convert to PDF/A (Tools…): PDF/A-2b, best effort. Adds an sRGB output intent and archival metadata, removes encryption, JavaScript and automatic actions, makes annotations printable with appearances, and reports what cannot be fixed here (fonts that are not embedded, attachments). The sRGB profile is generated by tools/make-srgb-icc.py.

## 0.44.0 (2026-11-24)

- Repair PDF (home screen › ⋮): rebuilds a damaged file into a new copy and says how many pages came back. It tries PDFium (which rebuilds a broken cross-reference table), then PdfBox's lenient reader, and, when the catalog itself is lost (a file cut short), rebuilds the page tree from the pages that survive. The original is never changed.

## 0.43.0 (2026-11-24)

- Edit properties (Tools…): title, author, subject and keywords. Optionally remove hidden metadata: the creating app, producer, dates, XMP and custom entries.

## 0.42.0 (2026-11-24)

- Protect with password (Tools…): AES-256 with a password to open, and optionally a separate permissions password that restricts printing, copying or editing. The dialog says plainly what this protects and what it does not.
- Remove password (Tools…): needs the password that opens the file (or the permissions password for a file anyone can open with restrictions).

## 0.41.0 (2026-11-24)

- Watermark (Tools…): text or an image, 15/30/50 % opacity, turned 0, 45 or 90 degrees, centred or tiled, over or under the content, on all pages or a range.

## 0.40.0 (2026-11-24)

- Page numbers (Tools…): six positions, formats "1", "1 / 10" and "Page 1 of 10" (in the app's language), three sizes, from a chosen page and starting number. Works on rotated and cropped pages.

## 0.39.0 (2026-11-24)

- Export as text (Tools…): plain text in reading order, or simple Markdown with headings (from font size and bold lines) and paragraphs, saved where you choose. Word, Excel and PowerPoint conversion is out of scope (it needs a layout engine; see the roadmap).

## 0.38.0 (2026-11-24)

- Extract images (Tools…): every picture in the document, once each, into a folder or a ZIP. JPEG photos are copied as they are (no quality loss); other images are saved as PNG; tiny icons are skipped.

## 0.37.0 (2026-11-24)

- Export as images (Tools…): PNG or JPEG at 72, 150 or 300 dpi, for all pages or a range, into a folder you choose or a ZIP to share.

## 0.36.0 (2026-11-24)

- Images to PDF (home screen › ⋮): pick photos with the system photo picker (no storage permission), put them in order, turn them, and choose the page (fit image, A4 or Letter), margin and orientation. The new PDF opens right away.

## 0.35.0 (2026-11-24)

- Compress (Tools… › Compress): light, recommended or strong. Images are re-encoded as JPEG and scaled down to the level's resolution (a new version is kept only when it is at least 10 % smaller), unused objects are dropped, and metadata can be removed too. Shows the size before and after; nothing is saved until you choose Save or Save as copy.
- The viewer menu has a new Tools… panel; Save flattened copy moved there.

## 0.34.0 (2026-11-24)

- Crop margins (Organize pages › ⋮ › Crop margins…): drag the corners or edges of the box over the page, or detect the white margins; apply to this page or to all pages (with detection, each page gets its own margins). Only the visible area changes; nothing is deleted.

## 0.33.0 (2026-11-24)

- Merge PDFs (home screen › ⋮): add several files, see the page count of each and the total, move them up or down, unlock protected ones with their password, and merge them into a new file that opens right away.

## 0.32.0 (2026-11-24)

- Split (Organize pages › ⋮ › Split…): every few pages, by ranges (each group a file), one file per page, or up to a file size. The files go to a folder you choose or into a ZIP to share.

## 0.31.0 (2026-11-24)

- Organize pages › Extract: the selected pages (in their order, with any rotation) become a new PDF saved where you choose; the open document does not change.

## 0.30.0 (2026-11-24)

- Organize pages › Insert: a blank page (same size as the page before, A4 or Letter) or pages from another PDF, with a page range such as 1-3, 5, 8- and a password prompt for protected files. New pages go after the selected ones.

## 0.29.0 (2026-11-24)

- Organize pages (Pages › Organize): select pages, rotate them left or right, duplicate or delete them, and long-press a page to drag it to a new place. Undo while organizing; Save writes the file, Save as copy leaves the original as it was.

## 0.28.0 (2026-11-24)

- Digital signature (Annotate… › Digital signature…): import a personal certificate (.p12 / .pfx), kept encrypted on the device with a key in the Android Keystore; its password is asked for each signature and never saved. Signs the document as PAdES-B (CAdES detached, SHA-256), with optional reason and place.
- Check signatures: says whether each signature is intact, whether the document changed after it, and whether the certificate comes from an authority the device trusts. Offline: no revocation or timestamp lookups.
- A signed document is saved as an incremental update, so adding annotations later keeps the signatures valid.
- New dependencies, used only when signing or checking: PdfBox-Android (Apache-2.0) and Bouncy Castle (MIT).

## 0.27.0 (2026-11-24)

- Stamps (Annotate… › Stamp…): Approved, Received, Confidential, Draft, the current date and time, and your own stamps (kept on the device, up to six). Placed with a tap as a framed bold label in the stamp's color.

## 0.26.0 (2026-11-24)

- Visual signature (Annotate… › Signature…): draw it with a finger or stylus, or take it from a photo (the white paper becomes transparent and the image is cropped to the ink). Up to three signatures or initials are kept on the device; pick one, drag it into place, resize it from the corner, and place it.

## 0.25.0 (2026-11-24)

- Fill and sign without a form (Annotate… panel): today's date, check mark, cross and dot, placed with a tap anywhere and kept on for as many as needed, in the pen color.
- The Annotate and View panels open at full height and scroll.

## 0.24.0 (2026-11-24)

- Fill PDF forms (AcroForm): tap a text field to type in it (keyboard for email and phone fields, password fields hidden), with Next field to move through the form; tap checkboxes and radio buttons to toggle them; lists and combo boxes open a choice dialog. Saved like annotations (Save, or Save as when the file is read-only); Save flattened copy turns the filled form into plain content.

## 0.23.0 (2026-11-24)

- Save flattened copy…: writes a copy where annotations (and form fields) are merged into the page content, so they look the same everywhere and can no longer be edited. The open document is not changed.

## 0.22.0 (2026-11-24)

- Save: annotations are written into the file itself when the app may write there (files picked in the app), or with Save as… otherwise; they are standard PDF annotations that other readers show.
- Leaving with unsaved changes asks: Save, Discard or Cancel.
- The viewer menu is shorter: Annotate… and View… open panels with those options.

## 0.21.0 (2026-11-24)

- Annotations tab in the pages sheet: every annotation grouped by page with its type, author and text; tap to go there, edit a note, or delete.
- Undo and redo for this session (buttons in the top bar) for adding, deleting and editing annotations.
- Your name in Settings is written as the author of your annotations.
- Annotations that came with the file can be deleted, but that cannot be undone in the session; the app says so.

## 0.20.0 (2026-11-24)

- Shapes (Shapes in the viewer menu): rectangle and ellipse (with optional fill), line, arrow and polygon. Drag to size them; for a polygon tap each corner and then Close shape. Line color and width come from the pen settings.

## 0.19.0 (2026-11-24)

- Sticky notes: Add note, tap where it goes, type the text; tap a note to read, edit or delete it.
- Text on the page: Add text, tap where it starts, then pick font (sans, serif, mono), size and color.
- Tapping any annotation shows it, with a Delete button.

## 0.18.0 (2026-11-24)

- Free-hand drawing (Draw in the viewer menu): one finger or the stylus draws ink, two fingers still scroll and zoom; pen color, width and opacity in the pen settings; the eraser removes whole strokes. Once a stylus is used, fingers only scroll (palm rejection). Strokes are standard ink annotations, kept in memory until saved.

## 0.17.0 (2026-11-24)

- Text markup from a selection: highlight (one tap in the selection bar), underline, strikethrough and squiggly underline, in a palette color or any hue. Added as standard PDF annotations to the open document; writing them to the file comes with saving (next steps).

## 0.16.0 (2026-11-24)

- Text selection can span pages: drag a handle onto the next (or previous) page and the copied text joins the pages.
- Copy page as image from the viewer menu: the current page goes to the clipboard as a PNG (about 150 dpi).

## 0.15.0 (2026-11-24)

- Search options: whole word and ignore accents (on by default, so "exportacao" finds "exportação"), next to match case.
- All results: a list of every match with a short excerpt around it, grouped by page; tap one to jump there.

## 0.14.1 (2026-11-24)

- Faster home screen start: plain text tabs instead of a Material TabRow, and favorites and folders load after the first frame.

## 0.14.0 (2026-11-24)

- Library on the home screen: Recent, Favorites and Folders tabs.
- Favorites: star any file (from Recent or a folder); starred files stay even after leaving the recent list.
- Folders: add folders through the system folder picker (persisted grant, no storage permission) and see the PDFs inside them and their subfolders, with search by name and sorting by name, date or size.

## 0.13.0 (2026-11-24)

- Attachments: files embedded in the PDF are listed in an Attachments tab of the pages sheet, and each can be saved anywhere (system Save screen) or shared.
- Save as now works for any file type (used by attachments and, later, exports).

## 0.12.0 (2026-11-24)

- Read aloud from the viewer menu with the system text-to-speech engine (offline when the voice is installed): starts at the current page, highlights the sentence being read and follows it, with play/pause, speed (0.75× to 2×) and stop.

## 0.11.0 (2026-11-24)

- New app icon: a white page on red. Works as a themed (monochrome) icon too.

## 0.10.0 (2026-11-24)

- Print from the viewer menu through the Android print framework (page ranges, copies and paper come from the system dialog). Password-protected PDFs are handed to the print service without their encryption, written on the fly by PDFium.

## 0.9.0 (2026-11-24)

- Document info from the viewer menu: title, author, subject, keywords, creator and producer, creation and modification dates, PDF version, page count, page size (named when it is A3/A4/A5/Letter/Legal/Tabloid), file size, and whether the PDF has a form, digital signatures or encryption.

## 0.8.0 (2026-11-24)

- Bookmarks: mark the current page from the viewer menu with an editable title (the contents entry of the page is suggested), see a ribbon on marked pages, and jump, rename or remove them from a Bookmarks tab in the pages sheet. Stored by the app; the PDF is not changed.

## 0.7.0 (2026-11-24)

- Page layout dialog in the viewer menu: continuous scroll (default) or page by page, with horizontal swipes that snap to whole pages.
- Two pages side by side in landscape and on tablets (page-by-page mode), with the first page alone as a cover by default.
- Optional right-to-left reading order for slots and spreads.

## 0.6.0 (2026-11-24)

- The exact reading position is remembered per document: page, offset inside it, zoom and horizontal position, restored when the file opens again.
- Fix: restoring the position no longer counts as scrolling, so full screen does not hide the bars right after opening.

## 0.5.0 (2026-11-24)

- Reading options in the viewer menu: keep screen on, lock rotation, and full screen while reading (the app and system bars hide once the page scrolls; a tap brings them back). Page padding ignores system bar visibility, so pages do not jump.

## 0.4.0 (2026-11-24)

- Page color for reading: normal, night or sepia, from the viewer menu. Applied as a color filter when drawing, so switching is instant and nothing is re-rendered; remembered globally, like the theme.

## 0.3.0 (2026-11-24)

- Contents: the document outline as an expandable tree in a new tab of the pages sheet; the branch of the current page starts open.
- Links: internal links jump inside the document and a "Back to page N" chip (or the system back) returns to where you were; web links ask before opening the browser (the app itself still has no internet permission).

## 0.2.0 (2026-11-24)

- Share a PDF from the viewer or from any recent file: the system share sheet gets a copy under the file's own name (FileProvider).
- Save a copy… to any folder the user picks (system Save screen), streamed with a cancellable progress dialog.
- Files that arrive through Open with/Share get a private copy in the background, so they can still be reopened, shared and saved after the temporary permission expires; copies of files no longer in the list are cleaned at the next start.
- Opening failures are logged without the file path.

## 0.1.0 (2026-11-24)

- First version: continuous scrolling, zoom, search, text selection, page thumbnails, recent files, password-protected PDFs, libre-apps themes, en/pt/es.
